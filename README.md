# Minecraft查询物品/成就

只是本人经常查配方要切换浏览器有些烦开发的...它可以在QQ群里发消息直接查物品配方、描述和成就，结果以图片返回

## 功能

- **物品查询**：描述 + 合成 / 熔炼 / 切石 / 锻造 / 酿造配方（多配方全发）
- **成就查询**：Java 版进度，含分类、描述、上游进度、实际需求
- **目录浏览**：物品 / 方块 / 成就 全目录，一次性发完

## 命令

| 命令 | 作用 |
| --- | --- |
| `.mq 物品名` | 查物品，先出描述图，再出配方图 |
| `.mq 物品` | 物品目录（所有页一次性发） |
| `.mq 方块` | 方块目录（所有页一次性发） |
| `.cj 成就名` | 查成就 / 进度 |
| `.cj 成就` | 成就目录 |

## 示例

```
.mq 铁锭
.mq 金合欢木按钮
.mq 方块
.cj 石器时代
.cj 成就
```

## 说明

- 数据基于 Minecraft Java 版原版，截至26.2版本内容(还包含一点26.3配方)
- 物品支持中文名查询，变体物品（如「云杉木门」）会自动归到父页面描述
- 查询结果以图片形式返回
- 工作台/熔炉等模板图来源于mc百科
- 是一个不完美的版本,可能有描述缺漏,贴图错误,材料字幕不是中文的情况发生,除此之外,一般情况下描述与配方是不会错的,可以放心使用
